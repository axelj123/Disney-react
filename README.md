# Disney+ Clone

Una réplica de la interfaz de Disney+ desarrollada con React y Vite, ofreciendo una experiencia similar a la plataforma de streaming original.

![image](https://github.com/user-attachments/assets/dc4740bd-9ba1-4a53-aa5e-16f70c0dc04b)


## ✨ Características

- 🎬 Catálogo de películas y series
- 🔍 Búsqueda y filtrado de contenido
- 🎥 Detalles de películas
- 🎯 Carruseles interactivos
- 📱 Diseño responsive
- 🌙 Modo oscuro
- 🎨 Interfaz fiel al diseño original de Disney+
- ❤️ Guardado de favoritos en la watchlist

## 🛠️ Tecnologías

- **React 18** - Biblioteca de interfaz de usuario
- **Vite** - Build tool y servidor de desarrollo
- **Tailwind CSS** - Framework de estilos
- **React Router** - Navegación
- **SWC** - Compilador de JavaScript/TypeScript

## 📋 Prerrequisitos

- Node.js (versión 14 o superior)
- npm o yarn

## 🚀 Instalación

1. Clonar el repositorio
```bash
git clone https://github.com/axelj123/Disney-react.git
cd Disney-react
```

2. Instalar dependencias
```bash
npm install
# o
yarn install
```

3. Iniciar el servidor de desarrollo
```bash
npm run dev
# o
yarn dev
```

## 📁 Estructura del Proyecto

```
Disney-react/
├── public/          # Archivos estáticos
├── src/             # Código fuente
│   ├── assets/      # Imágenes y recursos
│   ├── components/  # Componentes React
│   ├── constant/    # Constantes y configuraciones globales
│   ├── pages/       # Páginas/Rutas
│   ├── services/    # Servicios y lógica de negocio

├── index.html
├── package.json
├── tailwind.config.js
├── postcss.config.js
└── vite.config.js
```
